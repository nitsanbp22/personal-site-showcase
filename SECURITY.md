# Public Showcase Scope

This repository is a portfolio case study, not a copy of the production source repository.

## Intentionally excluded

The showcase does not include:

- personal phone-number implementation details
- private contact configuration
- the full media and video library
- local font files
- production source history
- unnecessary social tracking parameters
- private or unpublished project assets

## Why the original repository remains private

The source repository contains a large amount of media and direct-contact information that is useful for the live site but adds little value to a GitHub portfolio review.

Keeping the showcase separate makes the public repository smaller, easier to review, and more intentional.

## Publication review

Before making this repository public or adding screenshots:

- review every screenshot for personal data that should not be exposed
- do not upload font files
- do not copy the full production asset library
- keep direct phone-number configuration out of the showcase
- verify that any linked public profiles are intentionally public
- confirm the README accurately reflects the current live experience

The private source repository remains the canonical implementation.
